## 요약

Paper B Lemma 2.5에서 제시된 E[Ri^m] 공식 중 **m=3, m=4가 brute-force 결과와 불일치**합니다.
E[Ri] (m=1)과 E[Ri^2] (m=2)는 정확합니다.
E[Ri^2·Rj^2] cross-moment 공식 (식 7)도 불일치합니다.

---

## 1. 정확한 공식 (m=1, 2) — 논문과 일치

### E[Ri] (검증 통과)
```
논문: E[Ri] = ni·(N+1)/2
검증: ni=3, N=9 → 15.0000 (brute-force: 15.0000) ✓
```

### E[Ri^2] (검증 통과)
```
논문: E[Ri^2] = ni·(N-ni)·(N+1)/12 + ni²·(N+1)²/4
검증: ni=3, N=9 → 240.0000 (brute-force: 240.0000) ✓
      ni=2, N=4 → 26.6667 (brute-force: 26.6667) ✓
```

## 2. 오류 공식: E[Ri^3] — 논문과 불일치

### 논문 공식 (Lemma 2.5, p.11):
```
E[Ri^3] = ni²·(N+1)³/8 + ni·(N-ni)·(N+1)·(N+2)/24
```

### Brute-force 검증 결과:

| ni | N | 논문 공식 | Brute-force | 차이 |
|----|---|----------|-------------|------|
| 1 | 3 | 9.667 | **12.000** | -2.333 |
| 2 | 4 | 67.500 | **150.000** | -82.500 |
| 3 | 9 | 1207.500 | **4050.000** | -2842.500 |
| 2 | 6 | 122.667 | **441.000** | -318.333 |
| 4 | 10 | 3960.417 | **12100.000** | -8139.583 |

### 오류 심각도: **심각** — 모든 케이스에서 과소추정, 차이가 매우 큼

### 정확한 공식 (검증 완료):

E[Ri^m]은 multinomial expansion + power-sum cross-moment 접근법으로 계산:

```
E[S^3] = n·M(3) + 3·n·(n-1)·M(2,1) + n·(n-1)·(n-2)·M(1,1,1)
```

여기서:
- M(3) = p₃/N
- M(2,1) = (p₂·p₁ - p₃) / (N·(N-1))
- M(1,1,1) = (p₁³ - 3·p₂·p₁ + 2·p₃) / (N·(N-1)·(N-2))
- pᵣ = Σⱼ₌₁ᴺ jʳ (power sums)

간단히 정리하면:
```
E[S^3] = n²·(n+1)·N·(N+1)²/8
```

검증: ni=3, N=9 → 9·4·9·100/8 = 4050 ✓

## 3. 오류 공식: E[Ri^4] — 논문과 불일치

### 논문 공식 (Lemma 2.5, p.11):
```
E[Ri^4] = ni·(N-ni)·(N+1)·(2N+1)/30 + ni²·(N+1)²·(N-ni)/12 + ni⁴·(N+1)⁴/16
```

### Brute-force 검증 결과:

| ni | N | 논문 공식 | Brute-force | 차이 |
|----|---|----------|-------------|------|
| 1 | 3 | 20.533 | **32.667** | -12.133 |
| 2 | 4 | 647.667 | **880.667** | -233.000 |
| 3 | 9 | 51189.000 | **71442.000** | -20253.000 |
| 2 | 6 | 1738.067 | **3822.467** | -2084.400 |
| 4 | 10 | 172318.000 | **299406.800** | -127088.800 |

### 오류 심각도: **심각** — Jensen 부등식 위반 (E[Ri^4] < E[Ri^2]² 가 발생)

ni=3, N=9에서 논문 공식: 51189 < E[Ri^2]² = 240² = 57600.
이는 **수학적으로 불가능** (E[X^4] ≥ (E[X^2])² by Jensen's inequality).

### 정확한 공식 (검증 완료):

```
E[S^4] = n·M(4) + 4·n·(n-1)·M(3,1) + 3·n·(n-1)·M(2,2)
         + 6·n·(n-1)·(n-2)·M(2,1,1) + n·(n-1)·(n-2)·(n-3)·M(1,1,1,1)
```

여기서:
- M(4) = p₄/N
- M(3,1) = (p₃·p₁ - p₄) / (N·(N-1))
- M(2,2) = (p₂² - p₄) / (N·(N-1))
- M(2,1,1) = (p₂·p₁² - 2·p₃·p₁ - p₂² + 2·p₄) / (N·(N-1)·(N-2))
- M(1,1,1,1) = (p₁⁴ - 6·p₂·p₁² + 3·p₂² + 8·p₃·p₁ - 6·p₄) / (N·(N-1)·(N-2)·(N-3))

## 4. 오류 공식: E[Ri²·Rj²] — 논문과 불일치

### 논문 공식 (식 7, p.11):
```
E[Ri²·Rj²] = E[Ri²]·E[Rj²] - ni·nj·(N+1)²·(N-2)·(N-ni-nj) / (12·(N-1)·(N-3))
```

### Brute-force 검증 결과:

| ni | nj | N | 논문 공식 | Brute-force | 차이 |
|----|----|----|----------|-------------|------|
| 3 | 3 | 9 | 57567.188 | **50908.500** | +6658.688 |
| 2 | 2 | 4 | 711.111 | **547.333** | +163.778 |
| 2 | 3 | 6 | 6005.867 | **5182.100** | +823.767 |
| 3 | 2 | 9 | 27145.125 | **23814.000** | +3331.125 |
| 4 | 3 | 10 | 151558.889 | **131672.200** | +19886.689 |

### 오류 심각도: **심각** — 모든 케이스에서 과대추정

특히 ni=nj=2, N=4에서 논문의 보정항이 0 (N-ni-nj=0)이므로 E[Ri²]·E[Rj²]를 그대로 반환하나,
실제로는 Ri+Rj=N(N+1)/2라는 강한 제약으로 상관관계가 존재.

### 정확한 공식 (검증 완료):

```
E[Si²·Sj²] = ni·nj·M(2,2) + ni·nj·(ni+nj-2)·M(2,1,1) + ni·(ni-1)·nj·(nj-1)·M(1,1,1,1)
```

여기서 M(a,b,...) 함수는 위의 E[S^4] 공식과 동일한 power-sum cross-moment.

## 6. 오류 원인 추정

논문의 Lemma 2.5 공식은 sampling without replacement의 고차 모멘트를 계산하는 과정에서
**cross-moment 항의 누락 또는 계수 오류**로 추정됩니다:

- E[S^3]에서 M(2,1)과 M(1,1,1) 항이 누락된 것으로 보임
- E[S^4]에서 일부 multinomial 전개 항의 계수가 잘못된 것으로 보임
- 논문이 preprint 상태이므로 정오표를 통해 수정될 가능성이 높음

E[Ri^2] 공식이 정확한 이유는 2차 전개에서는 M(2)와 M(1,1) 두 항만 있어 오류 여지가 적기 때문입니다.

## 7. 코드 구현 현황

`kw_approx/moments.py`에 **power-sum 기반 정확한 공식**으로 구현 완료:
- `_rank_sum_moment(ni, N, m)`: E[Ri^m] for m=1..4 — **brute-force 전수 검증 통과**
- `_cross_moment_R2R2(ni, nj, N)`: E[Ri^2·Rj^2] — **brute-force 전수 검증 통과**
- `_compute_variance_paper()`: Var(H) — **Wallace 공식과 완전 일치**

이 구현은 논문의 잘못된 공식이 아닌, **독립적으로 유도한 정확한 수학적 공식**을 사용합니다.
